# Neha Thammineni - Resume Website

A simple responsive resume website built with HTML, CSS, and JavaScript.

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `neha_resume_website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension and select **Open with Live Server**.

## Save as PDF
Click **Download / Print Resume** at the bottom of the page, then choose **Save as PDF** in the browser print dialog.

## Files
- `index.html` — resume content and page structure
- `style.css` — layout, colors, responsive design, and print styling
- `script.js` — print button behavior

All resume details and wording have been kept as provided.
